# Crooked Halo

A richly illustrated supernatural text MMORPG prototype about strange covenants, shifting regions, and wayfarers following the Shattered Bell.

## Play locally

Run `node outputs/server.mjs` from the repository root, then open the local address it prints.

## Deploy

This repository includes a Render Blueprint configured for a free Node web service. The prototype stores accounts, characters, chat, and progress in each player’s browser. Shared multiplayer persistence requires a server and database.
